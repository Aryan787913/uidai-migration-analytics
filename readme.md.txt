# UIDAI Migration Analytics Project

This repository contains my submission for the UIDAI Data Hackathon 2026.
The analysis uses Aadhaar enrolment, demographic update and biometric datasets to uncover internal migration patterns across India.

## 🔍 Project Goals
- Build a Migration Index using demographic update behaviour
- Identify migration receiving and sending states
- Detect district-level migration hotspots
- Segment movement by age group (family migration vs job-led migration)
- Discover seasonal migration trends
- Forecast Aadhaar update demand for the next 12 months

## 📊 Key Outputs
- Top receiving states
- Top sending states
- Hot migration districts
- Age-based migration flows
- Seasonal pattern line chart
- Prophet-based forecasting

## 🛠 Tools & Libraries
Python, Pandas, NumPy, Matplotlib, Prophet, Jupyter Notebook
